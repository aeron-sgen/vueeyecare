# Vue Eyecare — redesign (design C, modern)

A static, platform-free rebuild of www.vueeyecare.com. It uses Vue Eyecare's own content, facts and photography, and is laid out in the Eye Trends (eyetrendsclearlake.com) site structure with a new design.

**Preview:** https://aeron-sgen.github.io/vueeyecare/ — a noindex copy, rebuilt from `dist/` on every push to `main` (`.github/workflows/pages.yml`). An earlier version lives in the private SGENCMS/vueeyecare repo.

- `dist/` is the site to deploy; see `docs/DEPLOY.md`.
- `docs/README.md` describes the layout, tools and rebuild steps; `docs/CHANGE-LOG.md` lists every structural and design decision.
- Open items for the practice are listed in `docs/README.md` → "Open for the practice".
